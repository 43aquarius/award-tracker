# 赛事管家 · Award Tracker

粘贴一段竞赛/评奖通知，自动提取关键信息，生成你的专属赛事日程。

本项目由 915 行的 Python 命令行工具 [award_tracker.py](award_tracker.py) 演化而来，现在提供**完全离线的 App 版本**——无需服务器、无需注册、数据只存在你自己的设备上。

![移动端截图](docs/screenshot-mobile.png)

## 下载安装

到 [Releases 页面](../../releases) 下载对应文件：

| 平台 | 文件 | 使用方式 |
|------|------|----------|
| Android 7.0+ | `award-tracker-v1.0.0.apk` | 下载后点开安装 |
| iPhone / 电脑浏览器 | `award-tracker-v1.0.0.html` | 下载后用浏览器直接打开 |

> **Android 安装提示**：首次安装会提示「来自未知来源」——这是因为应用不走应用商店分发，属正常提示，在系统设置中允许即可。本应用申请零项敏感权限、无任何网络访问，可放心安装。

## 功能一览

- **📋 智能解析**：粘贴通知原文，自动提取赛事名称、截止日期（年份智能推断，未注明时刻默认 23:59）、报名方式、参赛材料、年级 / 专业限制、链接；支持一次粘贴多条通知
- **🎯 画像匹配**：按你设置的年级与专业，给每条通知打标——「符合 / 待确认 / 年级不符」，只排序不过滤，不做误过滤
- **📅 月程月历**：月历视图总览当月赛事，每天的事项数角标，点击日期查看当日清单，3 天内截止自动红色预警
- **⏰ 临近提醒**：进入应用即见临近截止徽章与提醒条（提醒天数可自定义）
- **🗂 记录管理**：按「临近截止 / 已过期 / 截止未注明」筛选，名称搜索，删除需二次确认，入库自动查重（同名同截止）
- **💾 数据自主**：数据保存在本机 localStorage，支持一键导出 / 导入 JSON 备份，换机不丢数据

## 技术说明

- App 采用 WebView 外壳 + 单文件离线 HTML 架构：安装包仅 70KB，启动即用
- APK 由 `aapt2 + d8 + zipalign + apksigner` 手工工具链构建，minSdk 24 / targetSdk 34，v2+v3 签名
- 解析引擎完整移植自 Python 版，并修复了原版「单行标题块被 junk 过滤丢弃」的缺陷；为兼容旧版 WebView 避开了较新的 JS 语法
- AndroidManifest 未声明任何权限——应用物理上无法联网
